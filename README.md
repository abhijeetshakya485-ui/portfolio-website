## About The Project

This portfolio website represents my personal and professional journey, from growing up in a village in Uttar Pradesh to pursuing a B.Tech in Computer Science Engineering and exploring the fields of Artificial Intelligence, Machine Learning, and Software Development.

The goal of this project was to create a professional online presence where recruiters, developers, and fellow learners can learn about my background, skills, projects, certifications, and contact information.

## Challenges Faced During Development

### Responsive Design

One of the biggest challenges was making the portfolio responsive across different screen sizes. Several sections initially broke on smaller devices and required media queries and layout adjustments.

### Interactive Popups

Implementing dynamic skill popups with descriptions and animations required JavaScript event handling and DOM manipulation.

### Certificate Integration

Managing and linking PDF certificates correctly was challenging because file paths and GitHub deployment directories needed to match exactly.

### GitHub Pages Deployment

Configuring GitHub Pages and ensuring all assets, certificates, and links worked correctly after deployment required several iterations and testing.

### User Experience Improvements

Balancing simplicity, aesthetics, and functionality while maintaining a clean light-themed design required multiple UI refinements.
